# Модель Социальной Сети

Система взаимодействие пользователей в виртуальном пространстве.

## Технологический стек
* **Язык**: Python 3.12
* **Стандарт оформления**: PEP 8

---

## Описание сущностей системы

| Сущность | Реализация в коде | Описание |
| :--- | :--- | :--- |
| **Социальная сеть** | Класс `SocialNetwork` | Центральный узел системы, который хранит базу всех пользователей и управляет глобальной логикой. |
| **Пользователь** | Класс `User` | Объект, представляющий участника сети. Хранит уникальное имя и идентификатор доступа. |
| **Профиль** | Класс `Profile` | Совокупность данных пользователя: его имя, список загруженных фотографий и история переписки. |
| **Друзья** | Класс `Friends` | Коллекция (множество `set`), содержащая имена пользователей, с которыми установлена взаимная связь. |
| **Сообщения** | Класс `Message` | Объект, содержащий текст, имя отправителя и метку времени создания. |
| **Фотографии** | Класс `Photo` | Объект публикации, включающий описание (текстовое представление фото) и дату загрузки. |
| **Лента новостей** | Класс `NewsFeed` | Динамически формируемый поток публикаций всех пользователей, отсортированный по времени. |

---
  
## Команды интерфейса (CLI)

Запуск системы: `python main.py`

| Команда | Аргументы | Действие |
| :--- | :--- | :--- |
| **reg** | `[имя]` | Регистрация нового аккаунта |
| **login** | `[имя]` | Авторизация под существующим именем |
| **post** | `[текст]` | Создание новой публикации в ленту |
| **feed** | - | Просмотр всех публикаций |
| **add** | `[имя]` | Добавить пользователя в список друзей |
| **msg** | `[имя] [текст]` | Отправить личное сообщение пользователю |
| **inbox** | - | Просмотреть список входящих сообщений |
| **exit** | - | Завершение работы программы |
