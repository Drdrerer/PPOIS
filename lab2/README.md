# Справочник железнодорожных рейсов

Информационная система для управления базой данных железнодорожных рейсов с поддержкой сериализации в XML и постраничного отображения.

## Архитектура проекта

Проект реализован с использованием паттерна **MVC (Model-View-Controller)**, что позволяет разделить бизнес-логику, интерфейс и управление.

### Структура файлов:

* **`model.py`** — **Model**: Содержит структуру данных `TrainRecord` и логику `ScheduleModel`. Реализует работу с XML через:
    * **DOM** (xml.dom.minidom) — для записи данных в файл.
    * **SAX** (xml.sax) — для быстрого и эффективного чтения данных.
* **`view.py`** — **View (Helper)**: Содержит вспомогательный класс `Paginator` для логики распределения записей по страницам.
* **`AppController.py`** — **Controller**: Главный управляющий класс. Координирует действия пользователя, обновляет таблицу и взаимодействует с моделью.
* **Диалоговые окна (View/Controller)**:
    * `AddRecordDialog.py` — Окно добавления новой записи (с использованием `tkcalendar`).
    * `SearchDialog.py` — Окно расширенного поиска с собственной пагинацией результатов.
    * `DeleteDialog.py` — Окно удаления записей по заданным критериям.
* **`main.py`** — Точка входа в приложение.
* **`generator.py`** — Скрипт для автоматической генерации тестовых данных (60 рейсов).

## Функциональные возможности

1.  **Управление данными**: Добавление, удаление и просмотр железнодорожных рейсов.
2.  **Постраничная навигация (Пагинация)**: 
    * Возможность выбора количества записей на странице (10, 20, 50).
    * Навигация: "В начало", "Назад", "Вперед", "В конец".
3.  **Поиск**: Гибкий поиск по номеру поезда и станции отправления с выводом результатов в отдельную таблицу.
4.  **XML Сериализация**: 
    * Импорт данных из XML (SAX-парсер).
    * Экспорт данных в XML (DOM-парсер).
5.  **Валидация**: Проверка корректности ввода даты и времени при добавлении записей.

## Сценарии демонстрации системы

### Сценарий 1: Генерация и навигация
1. Запустите скрипт `generator.py` или воспользуйтесь функцией импорта.
2. В главном окне убедитесь, что записи отображаются постранично (по 10 записей).
3. Используйте кнопки навигации (Вперед/Назад/В начало/В конец) для перемещения по базе данных.
4. Измените количество записей на странице на "20" через выпадающий список и проверьте пересчет общего количества страниц.

### Сценарий 2: Поиск и фильтрация
1. Нажмите на кнопку «Поиск» в меню или на панели инструментов.
2. В открывшемся окне введите номер поезда (например, из списка существующих).
3. Нажмите кнопку «Искать». Результаты отобразятся в отдельной таблице внутри диалога.
4. Проверьте, что в окне поиска также работает пагинация, если результатов много.

### Сценарий 3: Добавление и удаление
1. Нажмите «Добавить», введите данные нового рейса. Используйте календарь для выбора даты.
2. Сохраните запись и найдите её на последней странице основной таблицы.
3. Нажмите «Удалить», введите номер только что созданного поезда и подтвердите действие.
4. Убедитесь, что запись исчезла из общего списка.

### Сценарий 4: Работа с файлами (XML)
1. Выполните «Файл -> Сохранить (DOM)» и выберите путь для сохранения XML-файла.
2. Полностью очистите текущую таблицу или перезапустите программу.
3. Выполните «Файл -> Загрузить (SAX)» и выберите ваш файл.
4. Проверьте, что все данные, включая время отправления и прибытия, восстановились корректно.

## Технологии

* **Python 3.12**
* **Tkinter** — графический интерфейс.
* **tkcalendar** — виджет календаря.
* **XML (SAX/DOM)** — хранение данных.

## Установка и запуск

1.  Убедитесь, что у вас установлен Python 3.12+.
2.  Установите необходимые зависимости:
    ```bash
    pip install tkcalendar
    ```
3.  Запустите приложение:
    ```bash
    python main.py
    ```
