# Отчет по лабораторной работе №4: Веб-интерфейс социальной сети

## 1. Описание проекта
Данный проект представляет собой развитие программной системы, созданной в рамках лабораторной работы №1. Исходная консольная архитектура была расширена до клиент-серверного веб-приложения. 

Главным достижением реализации является **полное переиспользование бизнес-логики**. Благодаря соблюдению принципов SOLID (в частности, Single Responsibility Principle), ядро системы (управление пользователями, графом друзей, сообщениями и лентой) было изначально изолировано от интерфейса. Это позволило подключить веб-слой без единого изменения в классах моделей данных.

## 2. Стек технологий
* **Язык:** Python 3
* **Веб-фреймворк:** Flask (выбран за лаконичность и минимальный overhead для синхронных задач)
* **Frontend:** HTML5, CSS3 (адаптивная верстка с темной темой, без сторонних UI-библиотек)
* **Хранение данных:** Сериализация объектов (Pickle) через единый файл `network_data.pkl`.

## 3. Выполнение требований задания
1. **Использование веб-фреймворка:** Серверная часть реализована на базе Flask (`app.py`), запросы обрабатываются через маршрутизацию (`@app.route`).
2. **Полнота пользовательского интерфейса:** Веб-версия поддерживает все функции CLI:
   * Регистрация и авторизация (с использованием сессий Flask).
   * Добавление других пользователей в друзья.
   * Публикация фотографий (постов).
   * Отправка личных сообщений.
   * Просмотр агрегированной ленты новостей и личного инбокса.
3. **Выделение общего кода:** Кодовая база разделена на три слоя:
   * **Core (Общий код):** `exceptions.py`, `friends.py`, `message.py`, `news_feed.py`, `photo.py`, `profile.py`, `social_network.py`, `user.py`.
   * **CLI Client:** `social_cli.py`, `main.py`.
   * **Web Client:** `app.py`, `templates/index.html`.

## 4. Демонстрация совместной работы (CLI + Web)
Архитектура поддерживает параллельное взаимодействие с базой данных как через консоль, так и через браузер. 

**Сценарий проверки:**
1. Запустить веб-сервер и авторизоваться под пользователем `UserA` в браузере.
2. Параллельно в терминале запустить CLI-клиент (`python main.py`) и авторизоваться под `UserB`.
3. Действия, совершенные `UserB` в терминале (например, отправка сообщения или публикация фото), моментально становятся доступны `UserA` в браузере при обновлении страницы, так как оба интерфейса обращаются к единому состоянию `SocialNetwork`.

## 5. Инструкция по запуску

**Подготовка окружения:**
```bash
pip install flask
```

**Запуск веб-версии:**

```bash
python app.py
```

После запуска сервер будет доступен в браузере по адресу: http://127.0.0.1:5000

**Запуск консольной версии (ЛР №1):**

```bash
python main.py
```
