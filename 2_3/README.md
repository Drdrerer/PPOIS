# 🏓 Pong

**Pong** — это продвинутая реализация классической аркады на языке **Python** с использованием библиотеки **Pygame**. Проект демонстрирует применение принципов объектно-ориентированного программирования (ООП), работу с сетевыми протоколами (UDP), систему частиц и гибкую настройку через внешние файлы конфигурации.

---

## Особенности проекта
* **Одиночный режим**: Игра против ИИ с тремя уровнями сложности (Easy, Medium, Hard).
* **Сетевой режим**: Полноценный мультиплеер (Хост и Клиент) через UDP-сокеты.
* **Визуальные эффекты**: Система частиц при столкновениях, динамические "хвосты" (trails) за объектами.
* **Звуковое сопровождение**: Индивидуальные звуки для ударов, голов, побед и поражений.
* **Система рекордов**: Сохранение лучших результатов в локальный JSON-файл.
* **Полная кастомизация**: Настройка баланса и внешнего вида через `config.json` без изменения исходного кода.

---

## Подробная структура модулей
Код разделен на 6 функциональных файлов для обеспечения принципа единственной ответственности:

1.  **`main.py`**
    * Точка входа.
    * Минималистичный запуск: создает экземпляр `PongGame` и инициирует главный метод `run()`.

2.  **`PongGame.py` (Ядро системы)**
    * Управляет конечным автоматом состояний (`MENU`, `PLAYING`, `WAITING`, `RECORDS` и др.).
    * Реализует основной цикл: `handle_events()` (ввод), `update()` (логика), `draw()` (рендер).
    * Отвечает за загрузку ассетов и управление сетевыми данными в реальном времени.

3.  **`Paddle.py` (Класс Ракетки)**
    * Логика перемещения игрока.
    * Алгоритм поведения бота (зависит от множителя сложности из конфига).
    * Отрисовка индивидуальных скинов и управление таймером визуального следа.

4.  **`Ball.py` (Класс Мяча)**
    * Математический расчет траектории и углов вращения.
    * Обработка коллизий с границами экрана и ракетками.
    * Метод `reset()` для возврата мяча в центр с выбором случайного направления.

5.  **`UDPNetwork.py` (Сетевой движок)**
    * Реализация неблокирующих UDP-сокетов.
    * Методы `host()` для создания сервера и `connect()` для подключения клиента.
    * Безопасная передача JSON-пакетов и метод `close()` для освобождения системных портов.

6.  **`Particle.py` (Эффекты и Константы)**
    * Хранит логику жизни отдельных частиц (прозрачность, затухание, движение).
    * Выступает центральным узлом для загрузки `config.json`, предоставляя глобальные переменные `WIDTH`, `HEIGHT` и `CONFIG` остальным модулям.

## Управление в игре

| Действие | Клавиши |
| :--- | :--- |
| **Движение ракетки** | `W` / `S` или `Стрелки вверх` / `вниз` |
| **Навигация в меню** | Цифровые клавиши `1`, `2`, `3`, `4` |
| **Назад / Выход** | `ESC` |
| **Ввод данных (IP/Имя)** | `Клавиатура` + `Enter` |

---

## Сетевая архитектура
Игра использует архитектуру **Client-Server** на базе протокола **UDP**:
* **Хост (Сервер)**: Рассчитывает положение мяча, обрабатывает столкновения и ведет официальный счет.
* **Клиент**: Отправляет координаты своей ракетки и отображает состояние игрового мира, полученное от Хоста.
* **Оптимизация**: Для плавности используется частота обновления 60 пакетов в секунду, что минимизирует задержки.

## Установка и запуск

### Требования
* Python 3.10 или выше.
* Установленная библиотека Pygame.

### Быстрый старт
1.  **Установите зависимости**:
    ```bash
    pip install pygame
    ```
2.  **Запустите игру**:
    ```bash
    python main.py
    ```
